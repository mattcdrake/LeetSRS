The five Chrome Web Store screenshots are numbered in listing order. Each has a 640 × 400 `*-preview.png` for checking legibility at store preview size. Store images are RGB PNGs without transparency.

The README banner displays at 800 pixels wide and the install button at 292 × 52; both are 2× PNGs with transparent rounded corners. The GitHub social preview is uploaded in the repository settings.

- `logos/`: SVG source and PNG icons at 16, 32, 48, 60, 96, and 128 pixels.
- `social/`: the 1200 × 630 website sharing preview and the 1280 × 640 GitHub preview.
