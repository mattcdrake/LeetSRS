# App icons

- `store-icon.png`: **128 × 128 PNG** for the Chrome Web Store's **Store icon** field.
- `icon.svg`: editable source using the approved store-image palette: green `#6acb7b` on `#141816`.
- `logo.png`: matching 128 × 128 branding asset.
- `../../public/icon/`: extension icons at 16, 32, 48, 60, 96, and 128 pixels.

The PNGs are rendered from the SVG at their target sizes and retain transparent corners around the circular background. The popup favicon uses `public/icon/32.png`.
