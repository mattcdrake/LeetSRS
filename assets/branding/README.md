# App icons

- [`128.png`](../../public/icon/128.png): **128 × 128 PNG** for the Chrome Web Store's **Store icon** field and other branding uses.
- [`icon.svg`](icon.svg): editable source using the approved store-image palette: green `#6acb7b` on `#141816`.
- [`public/icon/`](../../public/icon/): extension icons at 16, 32, 48, 60, 96, and 128 pixels.

The PNGs are rendered from the SVG at their target sizes and retain transparent corners around the circular background. The popup favicon uses [`public/icon/32.png`](../../public/icon/32.png).
