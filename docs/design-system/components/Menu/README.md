# Menu

The popover used for sort, filter and overflow menus.

Source: `menuPopover` and `menuItem` in `popup/styles.ts` (react-aria `Popover` / `Menu`).

- Popover: `surface`, 1px `line-strong`, `radius-lg`, `shadow-card`, padding 4, z-index 1100.
- Item: `control-md`, `radius-md`, `small`; focused `raised`; disabled opacity .5.
