# Difficulty

A LeetCode difficulty label with its dot.

Source: `popup/components/Difficulty.tsx`. Props: `difficulty` (`easy` | `medium` | `hard`), `tone` (`color` default, or `quiet`: only the dot is coloured and the label is `fg-2`, for use beside another coloured label).

Uses `difficulty-easy` / `difficulty-medium` / `difficulty-hard` only; the word always accompanies the colour.
