# LeetSRS Privacy Policy

**Last Updated: November 21, 2026**

Your learning data—cards, notes, review activity, and settings—stays on your device unless you turn on GitHub sync.

LeetSRS follows the Chrome Web Store Limited Use requirements. We do not sell your data, use it for advertising, or transfer it for purposes unrelated to LeetSRS. The extension does not collect analytics, crash reports, or other telemetry.

## Optional GitHub sync

If you turn on GitHub sync, LeetSRS stores your learning data in a Gist in your GitHub account to keep your devices in sync. Signing in alone does not turn on sync.

LeetSRS does not encrypt backups. New backups are secret Gists: **they are not private—anyone with the link can read them.**

GitHub sign-in uses a LeetSRS authentication service hosted on Cloudflare. The service does not receive your learning data or store your GitHub credentials. GitHub and Cloudflare handle data under their own privacy policies.

## Your controls

You can turn off sync or sign out at any time. Signing out disconnects sync and removes saved GitHub credentials from the extension, but keeps your learning data and backups. You can delete backups or revoke access through GitHub.

## Changes

We will update this policy when our data practices change. For questions, open an issue in the [LeetSRS repository](https://github.com/mattcdrake/LeetSRS/issues).
