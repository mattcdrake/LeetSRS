# LeetSRS Privacy Policy

**Last Updated: September 15, 2026**

By default, your learning data—cards, notes, review activity, and settings—stays on your device. Cloud features are optional.

LeetSRS follows the Chrome Web Store Limited Use requirements. We do not sell your data, use it for advertising, or transfer it for purposes unrelated to LeetSRS.

The extension does not send crash reports, usage analytics, or diagnostic telemetry to LeetSRS. Any future collection of this data will be disclosed in this policy before it begins and will require your explicit opt-in. This is separate from the connection metadata described below.

## Optional GitHub sync

If you enable GitHub sync, LeetSRS uploads your learning data to a Gist in your GitHub account and downloads it to keep your devices in sync. Signing in alone does not enable sync. GitHub authorization requests `gist` access to manage Gists and `offline_access` to renew access without repeated sign-ins.

Backups are stored as readable data in your GitHub account, without encryption by LeetSRS. New backups are secret Gists: **they are not private or access-controlled backups—anyone with the link can read them.** Existing backups keep their visibility.

LeetSRS uses an authentication service hosted on Cloudflare to handle GitHub sign-in and renew access. LeetSRS does not persist GitHub access credentials on its servers. The authentication service does not receive your learning data. Cloudflare processes connection metadata, including IP addresses. GitHub and Cloudflare handle data under their own privacy policies.

## Your controls

You can disable sync or sign out at any time. Signing out removes locally saved GitHub credentials and disconnects sync, but keeps your learning data and GitHub backups. You can delete backups or revoke access through GitHub.

## Changes

We will update this policy as our data practices change. For questions, open an issue in the [LeetSRS repository](https://github.com/mattcdrake/LeetSRS/issues).
