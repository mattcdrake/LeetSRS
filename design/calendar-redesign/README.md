# Calendar tab redesign: reference mockups

Static mockups for the Calendar tab redesign (Direction C, "Forecast"). These are design references, not app code. See the tracking issue for the spec and plan.

- `mockups/`: 370×550 renders at 2x, light and dark. `overview.png` is a contact sheet.
- `current/overview.png`: the current tab in each state it was reviewed in.
- `mock.js` and `mock.html`: the mockup source. `mock.js` has the exact Tailwind classes, and `mock.html?dir=C&scene=today|heavy|empty&theme=light|dark&lang=zh` renders a frame. Only direction C is current; A and B are the rejected alternatives.
- `proposed-tokens.css`: the proposed heat and warning tokens to add to `popup/App.css`.

Delete this folder once the redesign ships.
